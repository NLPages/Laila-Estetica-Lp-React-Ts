# Laila Pinheiro Estética Biomédica — Landing Page

Landing Page de alta conversão, responsiva e acessível desenvolvida para a clínica biomédica da **Dra. Laila Pinheiro** em Duque de Caxias, RJ.

## 📖 Documentação Técnica Completa

Para detalhes aprofundados sobre a **arquitetura do sistema**, o **design system**, a **origem dos dados (incluindo avaliações do Google)** e guia de manutenção, consulte o documento oficial na raiz do projeto:

👉 **[DOCUMENTACAO_TECNICA.md](./DOCUMENTACAO_TECNICA.md)**

---

## 🚀 Tecnologias

- **React 19** + **TypeScript**
- **Vite 6**
- **Tailwind CSS v4**
- **Oxlint**

## 🛠️ Comandos Principais

```bash
# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento local
npm run dev

# Gerar build de produção otimizada
npm run build

# Executar linter
npm run lint
```
